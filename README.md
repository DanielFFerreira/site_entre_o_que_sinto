# Entre o que sinto e o que não sei

Site pessoal em HTML, CSS e JavaScript puro, com ícones da biblioteca Remix Icon.

## Estrutura
- index.html
- css/style.css
- js/main.js

## Dependências externas
- Google Fonts (DM Sans e Playfair Display)
- Remix Icon 4.9.0, carregado por CDN

## Conceito
O projeto organiza um processo emocional em seis eixos: sentimentos, caminho do reencontro, diferença entre fato e interpretação, olhar inspirado na psicanálise, fé sem tentativa de controle e um diário pessoal salvo localmente no navegador.

O conteúdo foi escrito para registrar a experiência de quem sente, sem declarar como fato aquilo que a outra pessoa pensa ou sente.

## Executar
Abra `index.html` no navegador ou use Live Server.
